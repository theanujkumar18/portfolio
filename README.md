# SQL Sales Data Analysis

## Project Overview

This project analyzes sales data using MySQL
to identify sales trends, top products,
customers and regions.

## Tools Used

- MySQL
- SQL

## SQL Concepts

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- AVG
- CASE WHEN
- Subqueries
- Window Functions
- Date Functions

## Analysis

The project analyzes:

- Sales performance
- Product performance
- Category performance
- Region performance
- Customer performance
- Monthly sales and profit
